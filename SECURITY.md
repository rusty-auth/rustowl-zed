# Security policy

Please report vulnerabilities privately through GitHub's **Report a
vulnerability** flow for this repository. Do not open a public issue for a
suspected vulnerability.

This extension downloads release artifacts from two GitHub repositories:

- `rusty-auth/rustowl-zed` for the protocol adapter; and
- `cordx56/rustowl` for RustOwl itself.

Reports concerning RustOwl's compiler analysis or official release artifacts
should also be shared with the upstream RustOwl maintainers under their
security policy.
